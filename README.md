# Maken Invited — Fadli & Mawar

## Struktur
- `index.html` — halaman utama undangan.
- `assets/` — gambar, musik, dan aset lain yang dipakai oleh halaman.

## Menjalankan
Buka `index.html` di browser untuk uji lokal. Untuk hosting, unggah seluruh isi folder ini ke repositori GitHub, lalu aktifkan GitHub Pages pada branch/folder yang berisi `index.html`.

**Penting:** jangan mengunggah `index.html` saja. Folder `assets/` harus ikut diunggah agar gambar dan musik tampil.

Tautan lokasi Google Maps, RSVP WhatsApp, dan nomor DANA sudah dipasang pada versi ini.
